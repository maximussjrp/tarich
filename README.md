# Tarich Contabilidade — versão clássica

## Como abrir
Abra `index.html` no navegador (duplo clique). Não precisa de servidor.

## O que funciona
- Menu responsivo (mobile).
- Links de telefone/e-mail/WhatsApp.
- Formulário abre o e-mail do visitante (mailto).
- Mapa embutido do Google (sem API key).
